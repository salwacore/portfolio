# Salwa Min Allah – Portfolio

Built from the **Aurora** template (React + Vite).

## Run locally
```bash
npm install
npm run dev
```

## Edit your content
- `src/data.js` – name, text, skills, projects, links
- `src/template.js` – colours, fonts, corner radius
- `src/portfolio.css` – all styles (scoped under `.pf`)
- `src/components/` – Hero, Stats, About, Services, Projects, Experience, Testimonials, Contact, Footer

## Deploy
`npm run build` creates a `dist/` folder. Upload it to Netlify, Vercel, Cloudflare Pages, GitHub Pages or any static host.
